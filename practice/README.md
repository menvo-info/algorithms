# 300 Bài Code Thiếu Nhi – My Solutions

My C++ solutions to "300 bài code thiếu nhi" ("300 coding exercises for kids"), a well-known Vietnamese practice set for programming beginners. I worked through these exercises in my 1st–2nd year at HCMUTE to build my programming fundamentals.

## Structure

`practice/` – C++ source files for each exercise, grouped by topic:

| Folder | Topic |
|---|---|
| [`chuong-1/`](chuong-1) … [`chuong-5/`](chuong-5) | Chapters 1–5 of the exercise set |
| [`tinh-tong/`](tinh-tong) | Summation techniques |
| [`dat-linh-canh/`](dat-linh-canh) | Sentinel / flag technique, basic exercises |
| [`nhap-xuat-mang/`](nhap-xuat-mang) | Array input and output |
| [`tim-kiem-liet-ke/`](tim-kiem-liet-ke) | Searching and enumeration |
| [`tu-duy/`](tu-duy) | Logical thinking exercises |
| [`luyen-tap/`](luyen-tap) | Mixed practice |
